FileConnect is a web-based peer-to-peer (P2P) file-sharing application that enables users to transfer files directly between browsers using WebRTC. It uses a lightweight Node.js signaling server to establish connections between peers, while the actual file data is transmitted through a WebRTC data channel.

The application features room-based connections, drag-and-drop file selection, chunk-based file transfer, real-time progress updates, and configurable transfer settings for different network conditions.
